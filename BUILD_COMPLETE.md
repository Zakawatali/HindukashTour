## 🚀 Quick Start

### 1. Install & Run
```bash
pnpm install
pnpm dev
```
→ Open http://localhost:3000

### 2. Customize
- Change company name in `app/layout.tsx`
- Update colors in `app/globals.css`
- Add/edit tours in `lib/tours-data.ts`
- Update contact info in multiple files

### 3. Deploy
```bash
pnpm build
```
Push to GitHub → Connect to Vercel → Auto-deploys!
